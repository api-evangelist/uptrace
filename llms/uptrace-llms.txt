# Uptrace

> Open-source observability platform built on OpenTelemetry for distributed tracing, metrics, and logs.

## Features

Uptrace features including distributed tracing, metrics monitoring, log management, alerting, and SSO.

- [Grouping similar spans and events together](https://uptrace.dev/raw/features/traces/grouping.md): Optimize grouping by choosing stable span names, leveraging display.name, and providing custom fingerprints when needed.
- [Traces](https://uptrace.dev/raw/features/traces.md): Explore spans and traces in Uptrace using filters, aggregations, operation detail panels, and the full trace waterfall to find and diagnose errors.
- [Querying spans](https://uptrace.dev/raw/features/traces/querying-spans.md): Master the Uptrace span query language including identifiers, filters, grouping, and aggregates for traces, logs, and events.
- [Querying traces](https://uptrace.dev/raw/features/traces/querying-traces.md): Query distributed traces by filtering spans, logs, and events across services, and enrich root results with cross-join expressions that aggregate child spans within the same trace.
- [Grouping rules](https://uptrace.dev/raw/features/logs/grouping.md): Create Grok-style log grouping rules that normalize noisy messages and generate consistent fingerprints for recurring issues.
- [Logs and Errors](https://uptrace.dev/raw/features/logs.md): Browse grouped logs and errors in Uptrace, filter by service or severity, search by text or attribute, and inspect individual records with aggregated stats and per-entry details.
- [Querying Metrics](https://uptrace.dev/raw/features/metrics/querying.md): Write PromQL inspired metric queries with aliases, joins, and expressions that feed dashboards built in the UI or YAML.
- [PromQL compatibility](https://uptrace.dev/raw/features/metrics/promql-compat.md): See how Uptrace extends PromQL, which functions are supported, and how to adapt Prometheus queries or Grafana dashboards.
- [Metrics](https://uptrace.dev/raw/features/metrics.md): Monitor infrastructure and application metrics in Uptrace using pre-built dashboards with table and grid views, or explore any metric interactively with aggregations, grouping, and filters.
- [Error monitors](https://uptrace.dev/raw/features/alerting/error-monitors.md): Set up error monitors in Uptrace to receive alerts for specific log patterns, exception types, and severity levels. Customize alert names with Go templates.
- [Alerting](https://uptrace.dev/raw/features/alerting.md): Configure metric and error monitors in Uptrace to track infrastructure health, span latency, error rates, and log patterns. Get notified via Slack, PagerDuty, Teams, and more.
- [Metric monitors](https://uptrace.dev/raw/features/alerting/metric-monitors.md): Create metric monitors in Uptrace to alert on CPU, disk, network, span latency, error rates, and log volume using YAML-defined thresholds and rolling evaluation windows.
- [Notifications](https://uptrace.dev/raw/features/alerting/notifications.md): Configure Uptrace notification channels to receive alerts via Slack, PagerDuty, Microsoft Teams, Telegram, email, webhooks, and more. Control routing with Expr conditions.
- [Searching Spans and Logs](https://uptrace.dev/raw/features/searching.md): Search spans and logs using natural syntax with word filters, AND/OR logic, quoted phrases, negative filters, and scoped attribute queries.
- [Chart Annotations](https://uptrace.dev/raw/features/annotations.md): Mark deployments, incidents, and config changes on Uptrace charts via API so your team can correlate timeline events with metric and trace changes.
- [Dashboards](https://uptrace.dev/raw/features/dashboards.md): Build custom dashboards from spans, events, logs, and metrics using a graphical UI or YAML. Table and grid layouts, PromQL-style expressions, and auto-activating templates.
- [Dashboard YAML Templates](https://uptrace.dev/raw/features/dashboards/yaml.md): Complete reference for the Uptrace dashboard template YAML format, covering metadata, tables, grids, grid items, monitors, and composition.
- [Transformations](https://uptrace.dev/raw/features/transformations.md): Use YAML-based transformations and Expr filters to rename attributes, parse payloads, sample or drop telemetry, and build full-text indexes before data reaches Uptrace.
- [Operations & Functions Reference](https://uptrace.dev/raw/features/transformations/reference.md): Complete reference for all Uptrace transformation operation types and built-in Expr functions for spans, logs, events, and metric datapoints.
- [Service Graph](https://uptrace.dev/raw/features/service-graph.md): Visualize service dependencies, request flows, error rates, and latency across your infrastructure with Uptrace service graphs built from OpenTelemetry span relationships.
- [Using Uptrace and Grafana Together](https://uptrace.dev/raw/features/grafana.md): Use Uptrace as a Prometheus and Tempo data source in Grafana to query metrics with PromQL and browse traces — reuse existing dashboards without changing metric names.
- [Using Fixtures to Seed Uptrace Data](https://uptrace.dev/raw/features/fixtures.md): Define YAML or JSON fixtures that sync users, organizations, projects, and tokens so every Uptrace environment can be bootstrapped consistently.
- [JavaScript Source Maps](https://uptrace.dev/raw/features/sourcemaps.md): Automatically unminify JavaScript stack traces using source maps. Upload source maps via API or let Uptrace fetch them from URLs in error spans.
- [MCP Server](https://uptrace.dev/raw/features/mcp.md): Built-in Model Context Protocol server that lets AI assistants query spans, traces, metrics, alerts, and dashboards in Uptrace using natural language.
- [Observability as Code](https://uptrace.dev/raw/features/observability-as-code.md): Manage Uptrace organizations, projects, monitors, and notification channels with the Uptrace Terraform provider — version-controlled and reproducible across environments.
- [Uptrace Features](https://uptrace.dev/raw/features.md): Explore Uptrace features: alerting, dashboards, querying, service graphs, SSO, Grafana integration, and more.
- [Google Cloud Single Sign-On](https://uptrace.dev/raw/features/sso/google.md): Configure Google Cloud OpenID Connect SSO with Uptrace using OAuth clients, redirect URIs, and client credentials.
- [Okta Single Sign-On](https://uptrace.dev/raw/features/sso/okta.md): Configure Okta as a SAML 2.0 identity provider for Uptrace SSO using app integrations, attribute statements, and metadata URLs.
- [Keycloak Single Sign-On](https://uptrace.dev/raw/features/sso/keycloak.md): Deploy Keycloak and configure OpenID Connect SSO with Uptrace using realms, clients, redirect URIs, and client credentials.
